## Install

Open the site on your phone, then:

- **iPhone (Safari):** Share button → **Add to Home Screen**.
- **Android (Chrome):** menu (⋮) → **Install app** or **Add to Home screen**.

## Files

- `index.html` – the whole app (vanilla HTML, CSS and JS)
- `sw.js` – service worker for offline use. Bump `VERSION` when you change any file.
- `manifest.webmanifest`, `icons/` – home-screen name and icons
